# Antigravity compatibility note

This historical tool-note filename is retained for callers of the legacy
delegation alias. The installed Fleet profile, mode support and current model
catalog are authoritative; this note is not an executable or model allowlist.

Do not infer headless capability or subscription access from an old IDE binary
layout. Use the current managed native adapter through the existing TODO path.
A missing supported mode is a capability gap, not permission to launch another
user's desktop, prompt a protected session, install software or bypass policy.

Keep the assigned workspace bounded and processes hidden. An actual native run,
checks and an independent product review prove delivery. An IDE handoff message
or historical model recommendation does not.
