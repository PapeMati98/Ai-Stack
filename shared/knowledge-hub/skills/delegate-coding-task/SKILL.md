# Delegation compatibility alias

This name is retained for existing Kimi Work callers. It delegates to the
currently installed managed skills, not to a second router or a copied engine.
Resolve the active `agent-cli` or `agent-graph` skill through the installation
metadata; do not hardcode another operator's profile or manually copy payloads.

- One bounded leaf: `agent-cli`, using the existing TODO Pair maker/reviewer
  execution and targeted repair path.
- Real dependencies or useful parallel scopes: `agent-graph` with one TODO and
  the Graph's existing historical scout. Do not create a second planner.
- The competent current M/D parent plans once. Code goes to qualified K/W
  workers, with an independent product reviewer from another model lineage.
  Keep real checks, scoped UAT and explicit acceptance evidence.

Use the live managed model catalog, allowed modes and existing subscription
availability. A stale market note is not a new mandatory preflight for every
task. Unknown quota does not mean exhausted; confirmed limits are respected.
Explicit market research belongs to the existing model-radar/model-audit lane.

No assessment-contract, route/council chain, extra freshness gate, duplicate
receipt, recursive Fleet invocation or compulsory SKIP ceremony is introduced
by this alias. Model details are not maintained here.

Keep secrets and private account stores out of prompts. Use an isolated
assigned workspace and bounded inputs; a scope list is not an OS sandbox.
No paid API fallback, IAM expansion, production/publication, external contact,
file deletion or live authentication is authorized by delegation. Preserve the
owner's actual approvals, training opt-outs and current installation policy.
Verify a native run and the independent result before integration; report
unknown telemetry honestly. A message or ACK is not task execution.

Old tool notes and `scripts/delegate.sh` are historical compatibility material,
not an alternative substantive execution path. Do not execute them to bypass
the installed TODO path or resurrect retired model/policy settings.
