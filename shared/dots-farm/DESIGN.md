# DOTS pilot: bounded implementation contract

Owner approved implementation on 2026-10-08. Funding approved: USD 5 total per
rolling 30 days for two DOTS plus supervisor (5_000_000 integer microUSD).
Suggested allocation: observer 2_000_000, collector 2_000_000, supervisor 1_000_000.
Emergency reserve 500_000 is WITHIN global cap, never added to it. Real provider
and secret qualification still required before paid execution; no real mail or
target application writes authorized. Synthetic tests use explicit fake budgets.

Implement a portable stdlib Python runtime at shared/dots-farm. Not a copy of
OpenDots/Hermes. Hermes is a candidate supervisor transport; deterministic
scheduler, STOP, caps and leases do not rely on a model being awake. Prepare
Hermes profile/job configuration without invoking installed Hermes or migrating
Robert. Live VM/service deployment is NOT part of local candidate acceptance.

## Public interfaces (parent-owned; implementation nodes do not edit this file)

Import paths: dots_farm.store, dots_farm.adapters, dots_farm.hermes,
dots_farm.engine, dots_farm.cli. CLI entry shared/dots-farm/dots.py. Tests add
shared/dots-farm to sys.path; scheduler cwd is worktree root. Only stdlib imports.
No auto-deleted temp directories, external installs, network model calls or
business effects in tests. Fixtures retained at a fresh UUID subdirectory of
DOTS_TEST_ROOT, default shared/dots-farm/.test-runs (gitignored by parent).

All persisted structured values JSON-compatible. Integer microUSD only; reject
negative values, bool-as-int and nonfinite values. UTC seconds float for timestamps
(must be finite); ISO date metadata may be strings. Identity strings restricted to
safe [a-z0-9][a-z0-9_-]{0,63}; company/project identifiers similarly bounded.
Typed validation errors must not echo payloads/secrets into logs.

### store.py public API

class Store(path): creates SQLite store, opens short-lived connections safely;
WAL/busy_timeout; no cross-thread shared connection. Scope is controller service,
NOT an OS security sandbox. All data access explicitly dot-bound. Use per-DOTS
logical namespaces with rejected cross-organization references and document real
OS isolation qualification separately. Methods return dicts/lists with declared
keys or raise ValueError/PermissionError; budget failure uses ValueError.

- configure_budget(global_cap, emergency_reserve=0, period_start=None,
  period_seconds=2592000): preserve spent and held across config/restart; rolling
  30-day periods, never silently zero unresolved reservations. Initial default
  cap ZERO. New period can clear settled history from active totals but unknown
  holds persist; all current reservations count before decisions.
- create_dot(dot_id, config): config includes kind observer|collector|supervisor,
  org, project, grant_version=1, model='synthetic', interval_seconds=900,
  budget_micro_usd, allowed_actions list, allowed_peers list, max_queue=100,
  max_payload_bytes=16384. Reject existing IDs without replacing memory/config.
  Validate positive interval, budgets and bounds; grant updates explicit only.
- get_dot(dot_id): {id, config, paused, last_success, last_attempt, coverage_status,
  grant_version}; list_dots(): list same. pause(dot_id, paused=True) persists STOP.
- update_coverage(dot_id, status, now, success=False): status empty|ok|failed|
  inconclusive|pending; failure never advances last_success. Finite timestamps.
- claim(dot_id, owner, now, ttl): returns token int or None if live lease/paused;
  expired lease acquired with strictly greater token. assert_lease(dot_id, owner,
  token, now): raises PermissionError if expired, replaced or paused. release(...)
  only releases matching owner/token. Fencing checked at effect boundary.
- reserve(dot_id, reservation_id, amount, emergency=False, now=None): atomic
  transaction across per-DOTS and global cap, outstanding reservations and
  reserved emergency portion. Return {id, amount, status:'reserved'}. Same ID
  with identical parameters returns original; different parameters reject.
- settle(reservation_id, actual=None): known actual updates cost once and releases
  unused hold; None marks unknown and retains full hold. Actual above reservation
  recorded truthfully (can trigger overrun stop), never silently discarded.
  Idempotent same settlement, conflicting re-settlement rejects. Unknown may later
  be reconciled by known cost. budget_status(dot_id=None): {cap, spent, held,
  remaining, emergency_reserve, period_start, period_seconds, overrun}.
- remember(dot_id, memory_id, text, source_ref, observed_at, trust='untrusted'):
  persist bounded per-agent memory with source/date/revision; no authority derived
  from memory. retrieve(dot_id, query, limit=5, max_bytes=4096): bounded relevant
  active records, never whole history. correct(dot_id, memory_id, text,
  source_ref='owner'): revision increment, old memory invalidated; restart sees
  correction. Contradictions do not broaden grants.
- seen(dot_id, item_id): bool; mark_seen(dot_id, item_id): persisted.
- intent(dot_id, effect_id, action, target_ref, payload, grant_version): persists
  before external action; exact same retry returns original, conflicting input
  rejects. Payload private in controller db, never Office. {id,dot_id,action,
  target_ref,payload,grant_version,status} status pending|unknown|confirmed.
- effects(dot_id, status=None): list persisted effects.
- effect_status(dot_id, effect_id, status, target_receipt=None): monotonic;
  confirmed never reset on retries/restore; opaque target receipt only.

### adapters.py public API

- validate_decision(value, kind): accepts mapping with action ignore|alert|
  collect|needs_owner and reason_code (bounded safe enum/string), optional invoice
  fields {org,number,date,amount,currency}, no extra tool/script/authority keys.
  kind restricts observer to ignore/alert/needs_owner; collector to ignore/collect/
  needs_owner. Amount Decimal validation and real invoice field checks in engine.
  Return sanitized dict, never execute model text. No automatic issue-fix action.
- SyntheticSource(path): JSON list of {id, org, content, model_decision, invoice?}.
  poll(dot_config): returns list; explicit failure injection via fixture mapping
  {status:'failed'|'inconclusive',items:[]} raises fixed-code exception. Empty
  list is actual empty, not failure. Enforce caps and per-org source boundaries.
- SyntheticModel(): decide(config,item,memory): returns {decision: sanitized
  decision, cost_micro_usd:integer, usage:{input_tokens,output_tokens}} from
  explicit fixture model_decision, cost defaults 1. This is a transport simulator,
  not a significance classifier; never claim actual model-quality proof.
- SyntheticTarget(path): persistent SQLite target with put(effect_id,payload),
  lookup(effect_id). Return opaque {receipt: id, status:'confirmed'}. Invoice
  global target identity keyed by org+invoice identity (not collector instance),
  duplicate/restart yields one record. Timeout AFTER write injectable in fixture
  via field simulate_timeout_after_write=True; engine must reconcile lookup.
  count() for test evidence. No file deletion during initialize/reset.
- SyntheticOffice(path): send(message): allow only schema {event_id,dot_id,
  org,project,kind,reason_code,opaque_ref,hops,expires_at}; bounded typed metadata,
  hops<=2, TTL, dedupe; no content, invoice details, person fields or arbitrary
  strings. Persistent sink; count() tests. Peer capability checks in engine.
- OpenRouterModel(config, secret_resolver, transport=None): decide(config,item,
  memory) same response shape. No network unless config live_enabled AND explicit
  approved_budget AND qualified_model/provider AND secret_reference are present.
  Synthetic transport can exercise exact request locally. HTTPS hardcoded base
  https://openrouter.ai/api/v1/chat/completions; reject redirects, bounded response
  bytes/timeouts, no retry/fallback, exact allowed model and provider.order one,
  allow_fallbacks=false, data_collection='deny', zdr=true, max_tokens and no tools.
  Requested model must be in qualified allowlist, forbidden IDs/contributor denied.
  Pin cost ceiling using measured input/output upper bound and refreshed tariff;
  no fictional cost fallback; missing/ambiguous cost means None (held).
  Parse usage.cost with Decimal to microUSD conservative rounding. Validate actual
  model identity; model response schema strictly typed. Never return auth/prompt
  from error. Transport receives (url, headers, body, timeout, max_bytes), returns
  response dict; production default uses urllib without redirect handler.
- OpenRouterKeyManager(secret_resolver, secret_sink, transport=None):
  provision(dot_id, budget_micro_usd, approved=False, expires_at=None) -> opaque
  reference and hash metadata, no plaintext key in return/log. Explicit consent
  checked before HTTP; POST https://openrouter.ai/api/v1/keys with management key
  only, limit USD Decimal, limit_reset monthly, include_byok_in_limit true,
  name safe DOTS identity and expiry. Secret sink stores key centrally and returns
  opaque reference. A provisioning timeout is unknown, not auto-retry. Management
  secret cannot be given to inference DOTS. No actual API provisioning in tests.

Primary API sources checked 2026-10-08:
https://openrouter.ai/docs/api/api-reference/api-keys/create-a-new-api-key
https://openrouter.ai/docs/guides/routing/provider-selection
https://openrouter.ai/docs/guides/features/zdr
Provider caps are a secondary guard, local rolling ledger is authoritative for
5 USD/30 days. OpenRouter monthly reset is not equal to rolling 30 days.

### hermes.py public API

profile_plan(dot_config, base_path): returns bounded declarative dict for a NEW
HERMES_HOME per dot/supervisor, never clone an existing profile or load credentials.
cron script-only deterministic wake (no_agent true), no hidden global model/keys
fallback; dedicated secret reference and model pin; fresh memories; one writer.
supervisor_plan(base_path, budget_micro_usd=1000000) similarly. Return is candidate
configuration, not proof installed Hermes accepts it. Document current runtime
and compatibility as unqualified until bounded live tests. Existing Robert left
untouched. Supervisor opinions can suggest cadence/repair but never grant tools,
change budgets, release holds or bypass STOP. Control plane remains deterministic.

## Engine and CLI behavior

CLI --state absolute directory, --source synthetic JSON, commands init/create/
tick/status/pause/resume/memory/correct/reconcile/hermes-plan/demo. No implicit
live mode, remote writes or credential lookup. Runtime data separate from source.
Templates observer and collector with per-agent budgets, scope, schedule; create
requires org/project, command help actionable. Default explicit synthetic model.
Provide actual CLI subprocess journey and daemon/service CANDIDATE (not installed).

tick: due cadence determined in UTC; lease and fencing, config/version snapshot;
read newest items, code changes/dedup only; call Model for unseen bounded items,
atomic max-call reservation before inference; memory selected by bound query;
record exact known cost or retain unknown hold. Apply only allowlisted actions,
org match, valid invoice fields. Semantic alarm vs noise is model decision; no
alarm keyword gate. If interpretation unavailable, retain pending items and mark
coverage inconclusive. New ordinary noise may be marked seen after successful
classification; failed/cost unknown handling remains visible, no false green.
Persist intent before effect; recheck current STOP and lease/version before any
target or Office call. Target idempotency stable across DOTS and snapshot restore.
Unknown writes lookup and reconcile, never blind reissue. STOP itself works even
with hung model/supervisor. Pause change persists immediately via independent CLI.
Bound item queue, payload, retry count; missing schedule slots coalesce into one
poll, not replay storm. Daily timezone and DST either tested or explicit blocked
qualification; unsupported must fail clearly, no silent UTC substitute.
Optional typed peer messages must obey explicit allowed_peer/action grants, TTL,
hop/dedupe controls; no elevation through another DOTS (confused deputy).
All logs/status/Office carry neutral metadata only. Memory/contents stay in
private state, no stable Hub wiki or shared prompt cache; fixture snippets not logs.

Invoice collection in pilot writes synthetic draft target; production invoice/
tax decisions are not implemented or silently approved. Invalid/ambiguous org,
amount, identity => needs_owner, no target invoice. Bug escalation is bounded
metadata, never auto-programs new coding work without an explicit future grant.
