# Marketing Context

Use this skill when a team needs a reusable, evidence-backed context for product
marketing, positioning, messaging or customer discovery.

## Workflow

1. Read the supplied product, audience and evidence sources; record gaps.
2. Separate observed customer language from interpretation and recommendation.
3. Define ICP, jobs-to-be-done, pains, desired outcomes, alternatives and
   differentiated promise. Keep claims tied to a source or label them as hypotheses.
4. Produce a positioning and message map with proof, disqualifiers and open tests.
5. Stop at a draft or decision record. Publication, outreach, campaign setup and
   budget changes require explicit approval and a separate action contract.

Read [references/contract.md](references/contract.md) for the output schema and
quality gates. Use [references/trigger-cases.json](references/trigger-cases.json)
to decide whether this skill applies.

## Opt-in: review synthesis

Only when a task actually summarizes a large already-collected set of redacted
review records, read [references/review-synthesis.md](references/review-synthesis.md)
and optionally run `scripts/summarize_reviews.py`. Not a default step; no
collection, scraping, population claims, or extra acceptance gates.
