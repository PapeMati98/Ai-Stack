# Training campaign contract

## Before run

```text
campaign_id/objective/owner: ...
primary_metric/guardrails/min_effect: ...
baseline/sanity/one_batch_overfit: ...
data_hash/splits/temporal_or_group_OOS/final_holdout_lock: ...
model_hash/commit/environment_hash/hardware_snapshot: ...
ablation_matrix/DoE_or_HPO: ...
GPU_time_run_budget/stop_rule: ...
checkpoint_dir_outside_OneDrive: ...
reviewer_and_acceptance_ledger: ...
```

## Run and resume evidence

Record checkpoint lineage, model weights, optimizer, scheduler, RNG state, data cursor, step, metrics, GPU telemetry and costs. A resume proof must compare resumed and continuous execution under the declared determinism tolerance.

## Promotion package

```text
repro_package: commit, env, hashes, config, seeds, commands
primary_metric_and_CI: ...
OOS/robustness/parity: ...
guardrails/cost/tail_cases: ...
negative_results: ...
reviewer_independent: PASS | FAIL
promotion_gate: GO | NO-GO | REVISE
reason_and_rollback: ...
```

The final holdout is evaluated once after the comparison is locked. The training owner cannot be the sole promotion reviewer. For explicit local Arbor comparisons, the frozen manifest is hash-bound and an exclusive durable campaign claim is created before final scoring; staged parent-created final data, lesson conditions, and the separate AG export boundary are documented in [arbor-campaign.md](arbor-campaign.md). A local numeric result is not an independent review or promotion verdict.
