# Search Visibility

Use this skill to diagnose discoverability and create an ordered, measurable
visibility plan across search engines, answer engines and LLM citations.

## Workflow

1. Define site, pages, audience, locale, engine and measurement window.
2. Read current crawl, structured data, content and analytics evidence; mark
   inaccessible systems and volatile facts.
3. Separate technical, on-page, authority, answerability and citation findings.
4. Prioritize issues by user impact, evidence, effort, risk and reversibility.
5. Specify acceptance checks and monitoring before proposing any draft change.
6. Stop before publishing, indexing submission, backlink outreach or deployment.

[references/trigger-cases.json](references/trigger-cases.json) for routing.
