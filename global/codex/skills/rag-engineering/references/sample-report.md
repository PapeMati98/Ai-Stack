# Sample evaluator output

This is a **preserved sample** of the deterministic evaluator running on the
synthetic gold corpus shipped under
[`../fixtures/`](../fixtures/). It is generated by:

```powershell
python "<skill-dir>\scripts\evaluate_retrieval.py" compare `
  --corpus "<skill-dir>\fixtures\gold-corpus.json" `
  --baseline "<skill-dir>\fixtures\baseline-predictions.json" `
  --candidate "<skill-dir>\fixtures\candidate-predictions.json" `
  --output-dir "<skill-dir>\out\sample-compare"
```

The output is intentionally preserved so reviewers can inspect the
shape of the report and verify the failure-gate semantics without
running the evaluator themselves.

## Notes for reviewers

- Latency, token usage and cost are deliberately `UNKNOWN`. The evaluator
  never invents or estimates them.
- The evaluator never infers freshness from a missing timestamp. Every
  citation's `timestamp_zone` is `UTC` or `unknown`.
- The evaluator never writes to a Hub, never spawns a subprocess and
  never executes the system under evaluation; it operates on predictions
  that the pipeline authors have already produced.
- The evaluator never declares an "improvement"; it reports the
  critical-gate evidence and lets the human reviewer decide.
