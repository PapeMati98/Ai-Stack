# ML reconnaissance contract

## Modes

- `hf-read`: lokalny inventory, odczyt stron/metadanych i wyszukiwanie; bez pobierania, uploadu, Jobs, repo write i publikacji.
- `hf-act`: wylacznie po osobnym kontrakcie zawierajacym action, target, revision, scope, approval, sandbox, budget, rollback i acceptance. Domyslnie odmowa.

## Identity gate

When `~/.agents/huggingface-profile.json` exists, authenticated work must match
its `username` and organization membership using `hf auth whoami`. The profile
contains no token. A mismatch blocks the operation, and private resources remain
outside ordinary `hf-read` when the profile says `private_resources:
explicit-only`.
