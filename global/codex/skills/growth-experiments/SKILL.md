# Growth Experiments

Use this skill for a measurable experiment from hypothesis through decision,
including tracking, attribution, CRO and controlled A/B planning.

## Workflow

1. State the user problem, falsifiable hypothesis, primary metric and minimum
   worthwhile effect.
2. Define population, unit of randomization, variants, exposure, duration,
   sample assumptions, guardrails and stopping rules.
3. Audit instrumentation, attribution windows, eligibility and interference.
4. Produce an experiment card and analysis plan before reading outcomes.
5. Report effect size, uncertainty, guardrails, segments, data quality and decision.
6. Keep implementation, budget, campaign launch and traffic changes behind explicit
   approval and rollback criteria.
